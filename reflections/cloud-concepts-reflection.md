# Cloud Computing Concepts & Version Control Reflection

## 1. Cloud Services I Use Regularly
* **Google Drive:** A cloud storage and document collaboration service.
* **Netflix:** A video streaming platform that delivers entertainment content over the internet.
* **Messenger:** A communication and messaging platform.

## 2. Service and Deployment Models
* **Google Drive:**
  * **Service Model:** SaaS (Software as a Service)
  * **Deployment Model:** Public Cloud

* **Netflix:**
  * **Service Model:** SaaS (Software as a Service)
  * **Deployment Model:** Public Cloud

* **Messenger:**
  * **Service Model:** SaaS (Software as a Service)
  * **Deployment Model:** Public Cloud

## 3. Git & GitHub for Cloud Projects
Version control is critical when managing cloud infrastructure because infrastructure is often defined as code (IaC). Using Git and GitHub allows developers to track every change made to configurations, collaborate seamlessly across teams, and roll back to previous stable versions if errors occur, preventing costly downtime and security risks.
